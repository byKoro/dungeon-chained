# Playbooks

Step lists for the additions that repeat in this project. Each ends with a done checklist. Always finish with `npm run check` and the doc updates listed in `.agents/context/conventions.md` → "Work flow".

| Playbook | When |
|---|---|
| `add-room-piece.md` | New `map/*.json` layout (editor or by hand) |
| `add-enemy.md` | New enemy type / sprite sheet |
| `add-trap.md` | New hazard type for challenge rooms |
| `add-weapon.md` | New weapon on the chain |
| `add-sound.md` | New sound cue |
| `add-particle-effect.md` | New particle / juice effect |
| `add-ui-screen.md` | New DOM overlay screen or HUD element |
| `port-old-branch.md` | Bringing work from an old-base branch into current `main` |
