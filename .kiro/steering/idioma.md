# Idioma

Responder sempre em português do Brasil (pt-BR).

- Toda resposta ao usuário em pt-BR, inclusive aberturas, status antes de chamada de ferramenta, e resumo final.
- Preservar termos técnicos, nomes de API, comandos de CLI, nomes de arquivo e mensagens de erro no original (não traduzir).
- Comentários de código em pt-BR, salvo quando o projeto já usar outro idioma de forma consistente.
